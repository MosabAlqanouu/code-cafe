# ☕ Code Café

A multi-page website for an imaginary café made for students and developers.
Built as the first assignment of **Web Development 1** at the Islamic University of Gaza.

## Pages

| Page | What it has |
| --- | --- |
| `index.html` | Home page: hero section, story, menu, photo gallery, opening hours table, address, intro video |
| `reserve.html` | Table reservation form with required fields, date picker, dropdown and radio buttons |
| `thanks.html` | Confirmation page shown after submitting the form |

## What I practiced

- Page structure: `<!DOCTYPE html>`, `<head>`, meta tags, favicon
- Semantic elements: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `footer`
- In-page links (`#menu`, `#top`) and links between pages
- Tables with `thead`, `tbody`, `tfoot`, `caption`, `rowspan` and `colspan`
- Forms: `fieldset`, `legend`, `label`, text, email, date, select, radio, `required`
- Media: images with `alt` text and an embedded video

## Tech

HTML5 — CSS will be added in the next stage.

## Run it

Download the project and open `index.html` in any browser.
